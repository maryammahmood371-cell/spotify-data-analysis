# Spotify Data Analysis Project

## 📌 Problem Statement

The objective of this project is to analyze Spotify music data to understand trends in **song popularity and user listening behavior**.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🔄 Steps Performed

* Data cleaning and handling missing values
* Exploratory Data Analysis (EDA)
* Analysis of genre distribution
* Identification of top artists and songs
* Study of audio features affecting popularity

## 📊 Results / Insights

* Identified top-performing artists and genres
* Found relationships between audio features and song popularity
* Visualized key trends in user listening patterns

## 🎯 Conclusion

This analysis provides insights into music trends and helps understand what makes songs popular on Spotify.
